# Workflow contracts

The package includes capture-job-posting, assess-match, prepare-resume, prepare-cover-letter, company-research, interview-talking-points, mock-interview, and organize-job-search. Conversation viewers request named installed skills; refreshing an MCP connection supplies tools, not skills. New skills require a plugin update or marketplace resync.

Each workflow reads current context, proposes work for review, and uses bounded MCP operations only after the person authorizes saving. Mock interviews keep the live conversation in the provider and save reviewed feedback rather than a transcript. A button request does not prove research or saving completed.

All eight workflows read the packaged [shared Parcel behavior](../plugins/parcel/references/behavior.md). Responses always offer a concise next useful action based on the person's request and current saved state, using the derived Job next action when relevant. Blocked work offers an unblock step. Offers do not execute work or add approval barriers. Earlier chat results are snapshots; relevant records are read again before dependent preparation or changes. The MCP server also supplies this behavior in its initialization instructions for clients using tools without an installed skill. An onboarding skill is not required.

Resume, Cover Letter, and Interview response preparation require an independent veracity review of the final draft against the Career Profile and supplied sources. Use the host's supported read-only reviewer dispatch; select a suitable low-cost model only when model selection is available. Resolve unsupported claims before treating material as ready. When reviewer dispatch is unavailable, present the complete draft, disclose that independent review did not run, and ask for one conversational confirmation that the draft is accurate and may be saved. One affirmative response covers both; do not ask again for separate save approval. Corrected drafts need renewed confirmation. Report the outcome as user-confirmed, not independently reviewed.
