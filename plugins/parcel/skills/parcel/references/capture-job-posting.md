# Capture a Job posting

Identify the intended Job and read existing details and Posting before changing them. Check for duplicates before creating a Job; clarify the target when uncertain. Ask for a URL or pasted description when no source is available.

Retrieve the source with the host's browsing capabilities; Parcel does not fetch posting URLs. Prefer the employer's original listing, preserve its wording and URL, and extract only supported details. If access fails, ask for pasted text and report the gap. Check whether the listing is active and explain closed, expired or unavailable sources without automatically changing saved Job status.

Keep compensation bounds, currency and period, remote-location eligibility and other restrictions clear. An upper salary bound is not a lower bound; ambiguous currency or omitted details stay unresolved rather than being guessed or silently converted.

Present the proposed Job details and Posting for authorization under the shared save rules. Keep them consistent with the approved proposal and report partial saves accurately. Capturing evidence does not establish that a Job passes Filters, refresh an existing Match, or imply external application or a status change.
